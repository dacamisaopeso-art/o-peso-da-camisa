# Quem Sou Eu? — arquivo preservado

Retirado do site por solicitação do proprietário em 10/10/2026, devido à cobertura limitada de jogadores.

Esta pasta preserva os arquivos originais, banco de jogadores, fontes, correções, fotos, créditos, código e testes para eventual recuperação. O conteúdo dos arquivos foi mantido integralmente, com os mesmos hashes Git. As fotos continuam sujeitas às licenças individuais registradas em docs/quem-sou-eu-fotos.json; o arquivamento não altera esses requisitos.

A estrutura interna conserva os caminhos relativos originais. Para restaurar o jogo, devolver esses arquivos às posições anteriores no repositório, revisar temporada/elencos/licenças e recolocar o cartão no menu. Não restaurar automaticamente.

A pasta começa com sublinhado para ficar excluída da publicação padrão do Jekyll/GitHub Pages. O site ativo mantém somente Desafio das Lendas, Desafio da Champions e Jogo da Velha Futebol.
